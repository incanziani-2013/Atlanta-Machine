# ATLANTA MACHINE V1 (GOLDMINE AUDIO)

Drum sampler VST3 de 16 pads (4 bancos), hecho con JUCE 8.0.6 + CMake.

## Instalar
Copia la carpeta `ATLANTA MACHINE.vst3` a `C:\Program Files\Common Files\VST3\` y reescanea plugins en FL Studio.

## Compilar
GitHub Actions: workflow "Build ATLANTA MACHINE (Windows VST3)" (Actions > Run workflow).
